🤖 Setting AI API — Multi Provider

Pilih provider AI untuk menjalankan agen dengan LLM sungguhan. Jika dimatikan, pipeline pakai template lokal (tanpa API). API Key disimpan lokal di browser (localStorage) — tidak dikirim ke repo. Untuk deploy Vercel production, bisa juga pakai Environment Variables.

Mode Template
⚙️ Setting Per-Agent (Advanced)

Override provider/model per agen. Kosongkan untuk pakai setting global.

🔐 Vercel Environment Variables (Production)

Untuk production, set env di Vercel Dashboard → Settings → Environment Variables:

OPENAI_API_KEY=sk-... ANTHROPIC_API_KEY=sk-ant-... GEMINI_API_KEY=AIza... GROQ_API_KEY=gsk_... OPENROUTER_API_KEY=sk-or-... DEEPSEEK_API_KEY=sk-... MISTRAL_API_KEY=... AI_PROXY_ENABLED=true

Jika env ada, proxy /api/ai akan pakai key server — client tidak perlu input key.
